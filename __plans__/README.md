# Plans

Agent-authored plans for multi-step work on this app. One file per effort, named `<number>-<slug>.md` (e.g. `1-dark-mode.md`).

The Buildspace coding agent reads existing plans here before starting work, writes a plan here when asked to plan a change, and updates a plan's `Status:` line as work progresses. A plan records the goal, files to touch, approach, risks, and current status.

Plans are version-controlled alongside the code. Read, edit, or delete them freely — they're a working scratchpad for you and the agent, not a contract.
